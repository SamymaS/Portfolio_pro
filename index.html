Sameva

Une application qui transforme les habitudes en quêtes de jeu de rôle. L'utilisateur envoie une photo comme preuve, un modèle de vision lui attribue un score sur 100 et la récompense suit.

An app that turns daily habits into role-playing quests. Users send a photo as proof, a vision model scores it out of 100, and the reward follows.

  • Validation par IA, jamais bloquante. Une fonction Supabase appelle Claude Haiku Vision. Sous 70/100, la validation manuelle reste possible à demi-récompense.
  • Hors ligne d'abord. Architecture MVVM, cache Hive, synchronisation avec PostgreSQL protégé par des règles RLS.
  • Livré comme un produit. 29 000 lignes de Dart, 505 tests, trois workflows GitHub Actions qui publient l'APK signé. Abonnement Stripe.
  • AI validation that never blocks. A Supabase edge function calls Claude Haiku Vision. Below 70/100, manual validation stays available at half reward.
  • Offline first. MVVM architecture, Hive cache, sync with PostgreSQL behind row-level security.
  • Shipped like a product. 29,000 lines of Dart, 505 tests, three GitHub Actions workflows publishing a signed APK. Stripe subscription.

Flutter, Dart, Supabase, PostgreSQL, Hive, Claude API, Stripe, GitHub Actions, Figma, Rive

TicketFlow

Une billetterie avec réservation de sièges, paiement et billets QR en PDF, découpée en microservices et déployée sur un cluster Kubernetes Azure.

A ticketing platform with seat booking, payment and QR tickets as PDF, split into microservices and deployed on an Azure Kubernetes cluster.

  • Pas de double réservation. Verrou atomique Redis avec expiration sur chaque siège, contrainte d'unicité côté base.
  • Résilient aux pannes. Disjoncteur et délai d'attente autour du paiement, file BullMQ avec reprises et file des échecs, worker idempotent.
  • Infrastructure en code. Terraform provisionne AKS, ACR, Key Vault et stockage. Chaque push sur main construit quatre images et les déploie.
  • No double booking. Atomic Redis lock with expiry on every seat, plus a uniqueness constraint in the database.
  • Built to fail safely. Circuit breaker and timeout around payment, BullMQ queue with retries and dead letters, idempotent worker.
  • Infrastructure as code. Terraform provisions AKS, ACR, Key Vault and storage. Every push to main builds four images and deploys them.

Node.js, Express, React, PostgreSQL, Redis, BullMQ, MinIO, Kubernetes (AKS), Terraform, Traefik, GitHub Actions

MythraSona

Une plateforme familiale de livres audio : des histoires originales lues par des voix de synthèse, avec le texte surligné mot à mot pendant l'écoute.

A family audiobook platform: original stories read by synthetic voices, with the text highlighted word by word as it plays.

  • Monolithe modulaire. API FastAPI et workers asynchrones pour l'import, la transcription, l'alignement et l'indexation.
  • Synthèse vocale sans GPU. Mistral Voxtral et ElevenLabs fournissent les voix et les horodatages de mots, ce qui supprime une étape d'alignement.
  • Exploité comme en production. HTTPS sur réseau privé Tailscale, images publiées par GitHub Actions, décisions tracées en ADR.
  • Modular monolith. FastAPI service plus async workers for import, transcription, alignment and indexing.
  • Speech without a GPU. Mistral Voxtral and ElevenLabs provide the voices and the word timestamps, removing an alignment step.
  • Run like production. HTTPS on a private Tailscale network, images built by GitHub Actions, decisions recorded as ADRs.

Python, FastAPI, arq, Flutter, Docker Compose, Caddy, Tailscale, GitHub Actions, Figma

TikTok Live → Minecraft

Les cadeaux, likes et messages d'un live TikTok déclenchent des actions dans une partie Minecraft, en direct.

Gifts, likes and chat from a TikTok live stream trigger actions in a Minecraft game as they happen.

  • Pont local en Node.js. Lecture du live, moteur de règles configurable (« une rose, un zombie »), anti-doublon et temps de recharge.
  • Plugin Paper en Java 25. Douze actions en jeu, reçues par WebSocket authentifié par jeton, testées sur un vrai serveur.
  • Testable sans être en live. Simulateur d'événements et faux plugin pour développer hors ligne.
  • Local Node.js bridge. Reads the stream, runs configurable rules ("one rose, one zombie"), deduplicates and rate-limits.
  • Paper plugin in Java 25. Twelve in-game actions, received over a token-authenticated WebSocket, tested on a real server.
  • Testable without going live. Event simulator and fake plugin for offline development.

Node.js, WebSocket, Java, Paper API, Gradle
